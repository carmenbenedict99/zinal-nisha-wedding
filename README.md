# Zinal & Nisha — Wedding Reception Website

A responsive static wedding invitation website designed for GitHub Pages.

## Add your photos
Upload your couple cover photo as `assets/cover.jpg`.
Upload gallery photos as:
- `assets/memory-1.jpg`
- `assets/memory-2.jpg`
- `assets/memory-3.jpg`

You can add more gallery cards by copying one `<figure>...</figure>` block in `index.html` and changing its image filename and caption.

## Publish free with GitHub Pages
1. Sign in or create an account at https://github.com
2. Create a new repository named `zinal-nisha-wedding` (Public is simplest for GitHub Free Pages).
3. Upload `index.html`, this README, and the `assets` folder to the repository. On GitHub, use **Add file → Upload files**; drag in the files. For folders, upload the files inside the folder too.
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then press **Save**.
7. Wait a few minutes and refresh the Pages settings. GitHub will show the public website URL, usually `https://YOUR-USERNAME.github.io/zinal-nisha-wedding/`.

## Notes
- GitHub Pages hosting is free for public repositories. Because the repository is public, uploaded photos and source code are public too. Do not upload private or sensitive images.
- The QR image is generated by an external QR service when the website is opened, so visitors need internet access.
- This is a static site; it does not collect RSVPs or personal information.
